## 不变式（Invariants）

这些规则用于把“非确定性”纳入可控边界，任何阶段都不得违反。

### 工程安全

- 不启动服务（不跑 dev server / web server / 守护进程）
- 不破坏已有可用功能：改动要最小化、可回滚
- 不引入/不输出密钥：不写入仓库、不在日志里打印
- 引入依赖前先校验：来源、许可证、维护状态、版本选择理由与替代方案

### 过程可控

- 任何需求/实验要有 Spec（Spec is Truth），避免目标漂移
- 任何“完成”要有证据：诊断/测试/可回放产物，禁止以主观宣告代替
- 阶段完成 != 全局完成：需要明确当前阶段收敛了什么、仍遗留什么

### 最小动作

- 单轮只允许 1–3 个动作（小步迭代），避免“一轮做完一切”
- 高代价动作前做 Checkpoint：当前理解、目标、下一步、风险、证据计划
